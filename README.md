# DEADWOOD Relay — общий сервер комнат

Это небольшой сервер-посредник для кооператива DEADWOOD. Он не хранит учётные записи, миры или пароли: хост создаёт комнату, а игроки видят её в списке и входят одной кнопкой.

## Публикация на Render

1. Создай новый **Web Service** из этой папки или репозитория, где она лежит.
2. Выбери бесплатный план только для тестов либо свой постоянный тариф для игры с друзьями.
3. Команды уже описаны в `render.yaml`: `npm ci --omit=dev` и `node server.mjs`.
4. После появления адреса, например `https://deadwood-relay.onrender.com`, в файле рядом с `Deadwood.exe` заполни строку:

```text
relay=https://deadwood-relay.onrender.com
```

5. Раздай игрокам одну и ту же папку игры с этим файлом. В меню «КОМНАТА / ОНЛАЙН» они увидят список комнат и кнопку «ВОЙТИ В КОМНАТУ» — IP, порт и ключ не нужны.

## Локальная проверка

Нужен Node.js 22+:

```text
npm ci
npm test
npm start
```

Проверка сервера: `http://127.0.0.1:8787/healthz`.

## Ограничения

Комната существует, пока хост в игре. Сервер ограничивает комнату четырьмя игроками. Бесплатные планы облаков обычно засыпают при простое; для постоянного публичного сервера нужен владелец подключённого хостинга.
